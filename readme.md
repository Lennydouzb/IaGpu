## Dependencies

Virtual environment:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Packages:
```bash
pip install pandas requests pyarrow fastparquet argcomplete 
```

```bash
    sudo apt-get install libarrow-dev libparquet-dev
```
